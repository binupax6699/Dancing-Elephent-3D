# Dancing Elephant 3D

## Overview
A 3D character sculpt created in Blender for Hack Club Stardance

## Workflow & Process
* Reference: Gathered reference images from Google to map out anatomy and proportions.
* Blockout (Construction):** Shaped base cubes to correct proportions, then used a Boolean modifier to join all primitive meshes into a single solid base.
* Remesh: Applied a Remesh modifier to generate clean, unified geometry ready for sculpting.
* Sculpting: Detailed fine features including skin wrinkles, muscle structure, bone highlights, nails, and refined mesh textures.
* Poly Count: ~470,000 faces high-poly sculpt.
